A few things I've built.

Two full-stack projects, built end to end — from schema design to the interface.

HYDRA — water intake tracker

A full-stack hydration tracker with routes for logging intake, setting daily goals, and undoing entries. SQL aggregates and GROUP BY queries power a consecutive-day streak counter and a 7-day intake chart, and the UI includes a jug that fills in real time as you log water — built from scratch with no frontend framework.

A complete e-commerce application with product browsing, customization, authentication, a shopping cart, order processing, and an admin dashboard. Runs on a normalized MySQL schema connecting products, orders, users, and cart items, with the PHP backend wired directly to frontend forms for registration, login, and checkout.
